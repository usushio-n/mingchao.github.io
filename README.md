# 共鸣档案 · 鸣潮角色人格测试

《鸣潮》同人网页。回答 20 道题后，页面会从原有的 51 位候选中匹配一位共鸣者，展示角色立绘、普通话原声和五维性格分数。项目仅供学习与娱乐，答题和计分都在浏览器内完成。

## 本地运行

在仓库根目录启动静态服务器，然后打开 [本地测试页](http://127.0.0.1:8000/)。

```sh
python -m http.server 8000 --bind 127.0.0.1
```

项目采用原生 HTML、CSS 和 JavaScript。通过 GitHub Pages 部署时，发布包含 `index.html` 的仓库根目录即可。

## 题目与匹配

- 题目根据 Mini-IPIP 计分键改写为简体中文。外向性、宜人性、尽责性、情绪稳定性、开放性各 4 题，每题选 1–5 分。对反向题先用 `6 − 回答` 换算，再计算每个维度的平均分。页面把平均分线性换算为 0–100 分。
- 每位候选的五维数值由同人解读标注。页面比较五维平均分与角色向量的欧氏距离，选取距离最小的角色，完全并列时按角色档案顺序取第一位。
- 改写题目和角色匹配尚未做心理测量验证。五维分数用于娱乐和自我观察，不能用于诊断或正式测评。

题目和计分在 [assessment.js](./assessment.js)，角色映射在 [resonators.js](./resonators.js)。研究依据见 [Donnellan 等人（2006）](https://pubmed.ncbi.nlm.nih.gov/16768595/) 和 [Mini-IPIP 计分键](https://ipip.ori.org/MiniIPIPKey.htm)。

## 结果语音

提交最后一题会触发结果角色的原声。可以暂停或从头重播。浏览器限制自动播放时，点击「播放语音」即可收听。立绘和语音保存在项目内，逐个角色的上游链接见 [游戏素材来源](./assets/SOURCES.md)。
