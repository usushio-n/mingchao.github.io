# 共鸣档案 · 鸣潮角色人格测试

《鸣潮》同人网页。每次从 60 道题中抽取 20 道，答完后会匹配一位共鸣者，展示角色立绘、普通话原声和五维雷达图。项目仅供学习与娱乐，答题和计分都在浏览器内完成。

## 本地运行

在仓库根目录运行下列命令，然后打开 [本地测试页](http://127.0.0.1:8000/)。

```sh
npx --yes http-server . -a 127.0.0.1 -p 8000 -c-1
```

项目采用原生 HTML、CSS 和 JavaScript。语音拖动使用浏览器的媒体定位，本地预览请使用支持 HTTP Range 的静态服务器。通过 GitHub Pages 部署时，发布包含 `index.html` 的仓库根目录即可。

## 题目与匹配

- 题库保留参考 Mini-IPIP 改写的 20 道简体中文题，并新增 20 道日常题和 20 道《鸣潮》情境题。情境以今州、黑海岸、黎那汐塔等地区为背景，按题干想象即可作答。
- 每次开始或重测时，每个维度随机抽 4 道题，含 1 道游戏情境题及 3 道日常题，正向、反向各 2 道。每题选 1–5 分。反向题先用 `6 − 回答` 换算，再计算各维度的平均分。雷达图把平均分线性换算为 0–100 分，并在五个轴旁标注数值。
- 每位候选的五维数值由同人解读标注。页面比较五维平均分与角色向量的欧氏距离，选取距离最小的角色，完全并列时按角色档案顺序取第一位。
- 题库、抽题组合和角色匹配尚未做心理测量验证。五维分数用于娱乐和自我观察，不能用于诊断或正式测评。

题目和计分在 [assessment.js](./assessment.js)，角色映射在 [resonators.js](./resonators.js)。研究依据见 [Donnellan 等人（2006）](https://pubmed.ncbi.nlm.nih.gov/16768595/) 和 [Mini-IPIP 计分键](https://ipip.ori.org/MiniIPIPKey.htm)。

## 结果语音

提交最后一题会触发角色原声。点击或拖动进度条可以跳到指定位置。进度条左侧可播放、暂停或继续，右侧的「重播」会从头开始。浏览器限制自动播放时，可以点左侧的播放键。素材见 [游戏素材来源](./assets/SOURCES.md)。

## 开发中（WIP）

- **题目与角色映射**　用试答反馈校对日常题和情境题的措辞，检查不同抽题组合的结果分布，再调整角色向量。
- **立绘呈现**　统一唤取立绘与透明角色图的主体比例，继续校对小屏构图。
- **语音体验**　逐条复听裁切点与音量，补测 iOS Safari 和移动端内嵌浏览器的播放行为。
